ProxyFox 产品事实

关于功能、权限、数据处理和产品边界的可核对说明。内容以公开源代码、扩展清单和隐私政策为依据。

更新：2026-10-03维护者：ProxyFox适用：v1.4.3
一句话定义

ProxyFox 是一个免费、开源、Manifest V3 的 Chrome 代理配置与切换扩展。它管理用户自己的代理服务器，不销售代理线路，也不是 VPN。

核心事实

支持的模式
Direct、System、HTTP、HTTPS、SOCKS4、SOCKS5。
浏览器要求
Chrome 114 或更高版本；Manifest V3 Service Worker。
许可与价格
MIT License；免费使用；源代码公开。
数据位置
配置使用 chrome.storage.local 留在当前 Chrome 配置文件中，不使用 ProxyFox 云端账号或同步服务。
外部代码
不加载远程代码；不包含广告或分析脚本。
导入导出
使用 ProxyFox 版本化 JSON。默认导出移除用户名与密码，只有明确选择后才包含明文凭据。
语言
简体中文、繁体中文、英文、日文和韩文。

Chrome 权限为何存在

权限用途不用于
proxy读取并应用 Chrome 代理配置不会提供或运营代理服务器
storage在本地保存配置与偏好不会上传到 ProxyFox 账号
webRequest / webRequestAuthProvider为严格匹配当前主机和端口的代理认证挑战提供凭据不会读取或修改网页内容
<all_urls>Chrome 对跨站代理认证事件所需的主机范围不会注入内容脚本

能力边界

适合

开发与 QA 环境切换、认证代理、内网绕过、手动选择可预测路由，以及需要失败回滚的用户。

不适合

需要按 URL 自动选路、PAC 规则引擎、代理线路购买、系统级 VPN 或不同标签页使用不同代理的用户。

连接测试会临时应用候选配置、发起测试请求并恢复原设置。它不是持续健康监控，也不会绕过浏览器的 TLS 证书校验。
