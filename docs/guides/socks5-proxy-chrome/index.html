SOCKS5 / Chrome

在 Chrome 中配置 SOCKS5 代理

准备好可信 SOCKS5 服务的主机、端口和可选凭据后，可以用 ProxyFox 建立可重复切换的配置。

需要准备什么

  • 代理主机，例如 proxy.example.com 或 IP 地址。
  • 端口，例如 1080。
  • 如果服务要求认证，准备用户名和密码。
  • 一个您信任的 HTTP 或 HTTPS 测试地址。

ProxyFox 不提供 SOCKS5 服务器，也不会判断某个代理供应商是否可信。

配置步骤

  1. 在设置页添加配置并选择 SOCKS5。
  2. 主机字段只填写域名或 IP，不加 socks5://。
  3. 填写 1–65535 范围内的端口。
  4. 按服务要求填写认证信息。
  5. 添加需要直连的本地或企业域名。
  6. 运行连接测试，保存后再启用。

DNS 与浏览器边界

浏览器代理配置不等同于系统级网络隧道。其他应用不会自动使用该 SOCKS5 配置。实际名称解析行为还可能受到 Chrome、操作系统和代理能力影响；如需严格的系统级 DNS 或泄漏控制，应使用针对该需求设计的网络工具，而不是把浏览器扩展当作 VPN。

认证失败怎么办

  1. 确认协议确实是 SOCKS5，而不是 HTTP 或 SOCKS4。
  2. 核对主机和端口；认证匹配依赖这两个值。
  3. 确认服务是否允许用户名密码认证。
  4. 避免把前后空格复制进凭据。
  5. 用 Direct 模式确认基础网络正常。
凭据导出默认关闭。只有明确启用“导出时包含认证信息”后，JSON 才会包含明文用户名和密码。

验证与回退

连接测试会短暂应用候选配置，并在完成或失败后恢复当前设置。正式启用失败时，ProxyFox 也会尝试恢复 Chrome 代理和本地激活状态。
