ProxyFox/指南/绕过规则

Proxy bypass list

写出可读、可维护的代理白名单

白名单中的目标会直接连接，不经过当前代理。规则越明确，排查网络行为越容易。

支持的规则格式

# 本地开发
localhost
127.0.0.1

# 企业域名
*.company.example  # 同时覆盖根域名

# 私有网络
10.0.0.0/8
[::1]/128

每行一条规则。支持域名、通配符域名、IPv4、CIDR、IPv6，以及以 # 开始的整行或行内注释。

通配符的含义

*.example.com 会标准化为 Chrome 可识别的绕过规则，并覆盖根域名 example.com。不要写路径、查询参数或协议；绕过列表按主机匹配，不是 URL 路由器。

全局与配置级规则

全局白名单适合所有代理都应直连的目标，例如本地开发服务和企业内网。配置级白名单只属于某个代理。启用“使用全局白名单”时，两组规则会合并。

维护建议

  • 用注释说明规则的业务原因，而不只是重复域名。
  • 优先使用最小必要范围，避免过宽的通配符。
  • 修改全局规则后测试至少一个代理配置。
  • 遇到目标没有走代理时，先搜索是否被全局或配置级规则覆盖。
  • 定期导出不含凭据的备份，便于审查变化。

它不是自动切换规则

ProxyFox 的白名单只决定哪些目标绕过当前代理。它不会根据不同网站自动选择不同代理配置；需要这种能力时，应选择支持 PAC 或规则路由的工具。
