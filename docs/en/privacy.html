Privacy Policy

Welcome to the ProxyFox browser extension. This Privacy Policy explains what data ProxyFox processes on your device to provide proxy management, how that data is used, and how you can control it.

Data We Process

ProxyFox does not collect your personal data on developer-operated servers. To provide the proxy management features you choose to use, the extension processes the following data locally:

  • Proxy server configurations, including names, protocols, hosts, ports, and bypass rules
  • Proxy authentication usernames and passwords that you choose to enter
  • Interface and behavior settings such as language, refresh-after-switch, connection test URL, and timeout
  • A temporary recovery record used to restore the previous proxy state during a connection test

ProxyFox does not read, record, or build your browsing history. It does not use cookies to track users and does not include analytics, advertising, or profiling services.

Local Storage, Export, and Deletion

The data above is stored in the current Chrome profile with chrome.storage.local. It is not synchronized or uploaded to ProxyFox servers.

  • You can edit or delete proxy configurations at any time
  • Exports exclude usernames and passwords by default; credentials are written to the local JSON export only when you explicitly enable "Include authentication information"
  • Chrome removes the extension's local storage when you uninstall the extension
  • The connection test recovery record is removed when the test or a later recovery completes

Network Requests and Third-Party Proxies

When you activate a proxy configuration, Chrome routes network traffic through the proxy server you selected. You provide and control that proxy server. ProxyFox cannot control how it handles data, so only use proxy providers you trust.

When you explicitly select "Test connection," the extension sends one request through the candidate proxy to the test URL you configured. The default is https://www.gstatic.com/generate_204. The request can expose ordinary network information, such as your IP address and browser request information, to the proxy provider and test URL operator. ProxyFox does not receive this request data.

If a proxy requires authentication, the extension supplies saved credentials only when Chrome's proxy authentication challenge strictly matches the configured proxy host and port.

Permissions Explanation

ProxyFox requests only the permissions required for its single purpose: configuring, testing, and switching Chrome proxy settings.

  • proxy: Used to set and manage browser proxy configurations
  • storage: Used to store proxy configurations, bypass rules, and preferences locally
  • webRequest: Used to receive Chrome proxy authentication challenges
  • webRequestAuthProvider: Used to provide saved credentials to strictly matching proxy authentication challenges
  • <all_urls>: Required by Chrome's proxy authentication event filter; ProxyFox does not use it to read or modify page content

Data Sharing and Limited Use

  • ProxyFox does not sell, rent, or transfer your data to the developer or advertisers
  • ProxyFox does not use data for advertising, credit assessment, profiling, or purposes unrelated to proxy management
  • Except for the proxy server and connection test URL you select, or where required by law, we do not disclose data to third parties

ProxyFox's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Children's Privacy

The ProxyFox extension is not designed for or marketed to children under the age of 13. We do not knowingly collect personal information from children under 13.

Policy Updates

We may update this Privacy Policy from time to time. Any significant changes will be notified through the extension update channel or website. We encourage you to periodically review this policy to stay informed about how we are protecting your information.
