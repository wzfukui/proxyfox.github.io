Built for controlled networks

Details for development and testing

AUTH

Authenticated proxies

Credentials remain in the current Chrome profile and are used only for a strictly matching proxy challenge.

TEST

Pre-save test

Temporarily apply a candidate, report apply and network timing, then restore the previous setting.

RULE

Readable bypass rules

Use domains, wildcards, IP addresses, CIDR, IPv6, and full-line or inline comments.

JSON

Controlled exports

Credentials are removed by default and written as plaintext only after explicit opt-in.

MV3

Clear product boundary

What it does—and what it does not

Clear boundaries reduce wrong installs and make network behavior easier to judge.

ProxyFox does

  • Configure and switch proxy servers you control
  • Answer matching proxy authentication challenges
  • Manage local profiles and direct-bypass rules
  • Test a candidate and restore the active setting

ProxyFox does not

  • Provide, sell, or recommend proxy servers
  • Act as a VPN or change OS-wide networking
  • Bypass Chrome certificate validation
  • Currently switch proxies automatically by rule
