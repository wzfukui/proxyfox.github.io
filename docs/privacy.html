隐私政策

ProxyFox 不建立账号，不收集浏览历史，也不把代理配置发送给开发者。

核心结论

  • 代理配置、白名单、设置及可选凭据保存在当前 Chrome 配置文件的 chrome.storage.local 中。
  • ProxyFox 没有开发者后端，不包含广告、分析、遥测或用户画像服务。
  • 本地存储不等于加密保险库。任何能访问当前操作系统账户或 Chrome 配置文件的人，都可能接触这些数据。
  • 导出默认排除用户名和密码；只有您明确启用时，导出的 JSON 才包含明文凭据。

本地处理的数据

扩展保存您主动填写的代理名称、协议、主机、端口、认证信息、全局和配置级白名单、界面语言、刷新偏好及连接测试设置。卸载扩展时，Chrome 会删除该扩展的本地存储。

网络行为

启用配置后，Chrome 按您的选择把浏览器流量交给相应代理。代理由您提供和控制；请只使用可信服务。当您主动运行连接测试时，扩展会通过候选代理请求您配置的测试地址，完成后恢复先前设置。该请求可能向代理运营方和测试地址暴露普通网络信息，ProxyFox 不接收请求内容。

需要认证时，扩展仅在 Chrome 的代理认证挑战与当前候选或已启用配置的主机和端口严格匹配时提供凭据。

权限用途

  • proxy：设置和切换 Chrome 代理。
  • storage：在本地保存配置。
  • webRequest 与 webRequestAuthProvider：响应匹配的代理认证挑战。
  • <all_urls>：代理认证事件过滤器需要该主机范围；不用于读取或修改网页内容。

网站

proxyfox.io 是静态网站，不设置分析、广告或用户画像脚本。点击 Chrome Web Store、GitHub 或邮件链接后，目标服务适用其自己的隐私政策。

联系与变更

隐私问题可发送至 support@proxyfox.io，或通过 GitHub Issues 反馈。政策发生实质变化时，本页会更新生效日期。
