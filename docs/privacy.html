隐私政策

欢迎使用 ProxyFox 浏览器扩展程序。本隐私政策说明 ProxyFox 为提供代理管理功能而在您的设备上处理哪些数据、数据如何使用，以及您如何控制这些数据。

我们处理的数据

ProxyFox 不会将您的个人数据收集到开发者运营的服务器。为了提供您主动使用的代理管理功能，扩展会在本地处理：

  • 代理服务器配置，包括名称、协议、主机、端口及白名单规则
  • 您选择填写的代理认证用户名和密码
  • 语言、切换后刷新、连接测试地址和超时等界面与行为设置
  • 连接测试期间用于恢复原代理状态的临时恢复记录

ProxyFox 不读取、记录或建立您的浏览历史，不使用 Cookie 追踪用户，也不集成分析、广告或用户画像服务。

本地存储、导出与删除

上述配置使用 chrome.storage.local 保存在当前 Chrome 配置文件中，不会同步或上传到 ProxyFox 服务器。

  • 您可以随时编辑或删除代理配置
  • 导出默认不包含用户名和密码；只有在您明确开启“包含认证信息”后才会写入导出的本地 JSON 文件
  • 卸载扩展会由 Chrome 删除扩展的本地存储数据
  • 连接测试恢复记录会在测试结束或下次恢复完成后删除

网络请求和第三方代理

当您启用代理配置时，Chrome 会按您的选择将网络流量交给该代理服务器。代理服务器由您提供和控制，ProxyFox 无法控制其数据处理方式，请仅使用您信任的代理服务。

当您主动点击“测试连接”时，扩展会通过待测试代理向您配置的测试地址发送一次网络请求；默认测试地址为 https://www.gstatic.com/generate_204。该请求可能向代理服务商和测试地址运营方暴露常规网络信息，例如 IP 地址和浏览器请求信息。ProxyFox 不接收该请求数据。

如代理需要认证，扩展仅在 Chrome 发出的代理认证挑战与您配置的代理主机和端口严格匹配时提供相应凭据。

权限说明

ProxyFox 仅请求实现其单一用途——配置、测试和切换 Chrome 代理——所需的权限：

  • proxy：用于设置和管理浏览器代理配置
  • storage：用于在本地保存代理配置、白名单和偏好设置
  • webRequest：用于接收 Chrome 的代理认证挑战
  • webRequestAuthProvider：用于向严格匹配的代理认证挑战提供您保存的凭据
  • <all_urls>：Chrome 代理认证事件过滤器需要该主机范围；ProxyFox 不使用它读取或修改网页内容

数据共享与有限使用

  • ProxyFox 不出售、出租或向开发者及广告商传输您的数据
  • ProxyFox 不使用数据进行广告、信用评估、用户画像或与代理管理无关的用途
  • 除您主动选择的代理服务器、连接测试地址以及法律要求外，我们不向第三方披露数据

ProxyFox 对通过 Chrome API 获得的信息的使用将遵守 Chrome Web Store 用户数据政策，包括有限使用要求。

儿童隐私

ProxyFox 扩展程序不针对 13 岁以下儿童设计或营销。我们不会故意收集 13 岁以下儿童的个人信息。

政策更新

我们可能会不时更新本隐私政策。任何重大变更都会通过扩展程序更新渠道或网站通知。我们鼓励您定期查看本政策以了解我们如何保护您的信息。
